A solução

Uma câmera criada para simplificar a rotina de estudos.

A Câmera Jovi é a solução desenvolvida pela equipe para o Challenge: uma plataforma web que aproxima captura, organização e aprendizado em uma experiência única.

O CHALLENGE

Transformar registros do cotidiano em conhecimento útil.

O projeto parte de uma situação comum entre estudantes: muita informação é capturada durante as aulas, mas pouco desse conteúdo permanece organizado para consultas e revisões futuras.

O PROBLEMA

O conteúdo fica espalhado.

Fotos, anotações e exercícios acabam separados em diferentes lugares, aumentando o tempo gasto para encontrar e compreender cada informação.

A PROPOSTA

Um fluxo simples e conectado.

A Jovi utiliza a câmera como ponto de entrada e conecta interface, backend e inteligência artificial para devolver materiais claros e organizados.

COMO FUNCIONA

Público-alvo

Para quem estuda hoje e constrói o amanhã.

A Jovi foi pensada para estudantes que dividem o tempo entre aulas, projetos, documentação, código e revisão de conteúdo.

“Tecnologia deve diminuir a distância entre capturar uma informação e realmente aprender com ela.”

03
